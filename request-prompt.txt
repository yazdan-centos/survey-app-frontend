Response includes fields like:

id

updatedAt
2) Authenticated user profile survey endpoints
Base route:

/api/users/me
Endpoints:

GET /api/users/me/active-surveys
GET /api/users/me/participated-surveys
GET /api/users/me/surveys/{surveyId}/results
Important:

/results is only an access check, not the actual result payload endpoint
it returns success/failure for authorization, not survey results JSON
3) Active survey response shape
Active surveys return items with:

survey
assignmentId
assignmentStatus
activeFrom
activeUntil
Important:

survey is not just an ID; it is a survey DTO object
preserve/use assignmentId because response submission depends on it
4) Participated survey response shape
Participated surveys return items with:

survey
responseId
submittedAt
5) Survey response submission contract changed
Survey response create/update now supports:

role
surveyAssignmentId
answers
demographics
Important:

for assigned user flows, submit surveyAssignmentId
do not substitute surveyId for surveyAssignmentId
6) Survey response details now may include
id
role
respondentUsername
userId
surveyId
surveyAssignmentId
submittedAt
answers
demographics
createdAt
updatedAt
Important:

related IDs may be nullable in some cases

7) Existing survey CRUD remains separate
Existing survey CRUD still uses /api/v1/surveys.

Important:

do not “normalize” new endpoints into /api/v1/...
